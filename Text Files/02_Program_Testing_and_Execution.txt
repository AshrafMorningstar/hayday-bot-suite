### Key Fixes & Root Cause Analysis

1. **Focus Hijack by Google Play Services Fixed**:
   - On this LDPlayer emulator, launching Hay Day triggered Google Play Services (`com.google.android.gms/.auth.uiflows.addaccount.*`) to repeatedly display a `"Checking info..."` / account sign-in overlay.
   - When the overlay stole focus during game engine initialization, Android paused the game process, causing Frida's connection to terminate.
   - **Resolution**: Disabled the intrusive Google Add-Account activities (`PreAddAccountActivity`, `WrapperControlledActivity`, `AccountIntroActivity`, `UnpackingRedirectActivity`). The game now boots without focus interruption.

2. **File Cleanup & Staging Robustness**:
   - Replaced fragile `chattr -R` calls in [loader.py](file:///c:/Users/Admin/Documents/inxernal-main/loader.py) with `find ... -exec chattr -i {} +` to ensure immutable flags are reliably removed regardless of toybox/busybox implementation limits.

3. **Background Process Deduplication**:
   - Cleaned up lingering background loader retries that were competing for ports and sending conflicting process signals.

4. **Control Socket `loadnative` Command**:
   - Added `loadnative` and `native` handlers directly to the TCP control socket (`127.0.0.1:31350`), allowing external GUI tools and scripts to bootstrap the native engine dynamically.
