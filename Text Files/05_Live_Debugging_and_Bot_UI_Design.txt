### 1. Universal Substring Search Across All Product Pickers

* **Our Implementation**:

  * Typing any substring matches across all 407 food products, recipes, production buildings, animals, tools, expansion items, and plots.

### 2. Preventing Frida from Hijacking Houdini's Crash / Fault Handlers
* **The Issue**: When attaching with Frida's default POSIX signal interception, Frida installs its own signal handlers for `SIGSEGV`, `SIGBUS`, and `SIGILL`. Under Android x86/x64 emulators (LDPlayer 9 with Houdini ARM64 translation), Houdini uses deliberate memory faults (guard pages, null pointer checks, JIT translation transitions) as normal execution control flow. When Frida intercepts these signals, Houdini's internal handler is bypassed, causing the game process to terminate or freeze seconds after the farm renders.
* **Our Implementation**:
  * In [`java_guard.ts`](file:///c:/Users/Admin/Documents/inxernal-main/java_guard.ts) / [`hook.js`](file:///c:/Users/Admin/Documents/inxernal-main/hook.js), any fault outside our allocated sentinel range (`0x7fff0000`–`0x80010000`) returns `false` without modifying context, preserving Houdini's native signal dispatch

### 5. Collecting Nests: Honey & Peanut Bags + Full Barn Rejections
