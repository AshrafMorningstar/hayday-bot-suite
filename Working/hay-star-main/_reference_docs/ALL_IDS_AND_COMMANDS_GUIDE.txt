 1. QUICK START: HOW TO OPEN AND USE THE BOT (1-CLICK)
================================================================================
You have a full Graphical User Interface (GUI) with buttons and live controls!

TO LAUNCH THE GUI:
  Simply double-click:
    start_gui.bat

WHEN THE GUI OPENS:
  1. Click "Connect / Start Backend".
     -> The bot connects to Hay Day and waits in STANDBY mode.
     -> It will NOT touch your farm until YOU tell it to!
  2. Under "Step 1: Choose What You Want To Do", check or uncheck boxes:
     [X] Harvest & Replant Crops
     [X] Collect Animal Goods
     [X] Feed Livestock
     [X] Collect Finished Machine Items
     [X] Queue Production Recipes
     [X] Harvest Orchard Trees & Bushes
     [ ] Auto-Sell Surplus in Roadside Shop
  3. Click "START AUTOMATION LOOP" (Green button).
     -> The bot will automatically farm ONLY the things you checked!

 2. HOW TO STOP COMMANDS AT ANY TIME
================================================================================
You are always in 100% control:
  - Inside the GUI: Click the big RED button:
      "STOP ALL COMMANDS" (or "STOP ALL" in the top bar).
  - In the Live Terminal: Type:
      stop
    and press Enter.
  - In the command prompt console: Press:
      Ctrl + C
All background farming and waiting cycles will halt immediately.

 3. WHAT ARE "GLOBAL ID CODES" AND HOW DO THEY WORK?
================================================================================
Inside Hay Day's computer code, every single item, building, plant, and animal
has a 7-digit ID number called a "Global ID".

The rule is very simple:
  The FIRST 1 or 2 digits tell the game WHAT TYPE of object it is (Class ID):
    - Class  4  (starts with 400...)  = Field Crops & Plants
    - Class  6  (starts with 600...)  = Animal Feeds
    - Class 11  (starts with 1100...) = Food Recipes, Dairy, Bread, Harvests
    - Class 13  (starts with 1300...) = Buildings, Machines, Pens, Trees, Bushes
    - Class 18  (starts with 1800...) = Tools (Axes, Saws) & Upgrade Materials
    - Class 23  (starts with 2300...) = Live Animals (Chickens, Cows, Pigs)

  The LAST digits tell the game WHICH item it is in that list.

 5. HOW TO RUN ANY COMMAND IN GAME (COPY & PASTE EXAMPLES)
================================================================================
You can trigger any action in real-time using `exec_cmd` in the GUI's Live
Terminal or in the Command Builder tab:

  SYNTAX:
    exec_cmd <vtable_hex> <targetId> [param2]

  CORE VTABLES (What type of action):
    0x014aae28 = Feed Animals
    0x014a63f8 = Collect from Building or Machine
    0x014a7d88 = Collect from Animal Habitat
    0x014a9cc8 = Queue Recipe in Machine

  COPY & PASTE EXAMPLES:

  1. Bake Bread in Bakery:
     exec_cmd 0x14a9cc8 1100015 1300082
     (Recipe: 1100015 Bread, Machine: 1300082 Bakery)

  2. Make Cream in Dairy:
     exec_cmd 0x14a9cc8 1100000 1300005
     (Recipe: 1100000 Cream, Machine: 1300005 Dairy)

  3. Make Brown Sugar in Sugar Mill:
     exec_cmd 0x14a9cc8 1100013 1300025
     (Recipe: 1100013 Brown Sugar, Machine: 1300025 Sugar Mill)

  4. Feed Chicken #1 with Chicken Feed:
     exec_cmd 0x14aae28 2300000 600002
     (Animal: 2300000 Chicken, Feed: 600002 Chicken Feed)

  5. Feed Cow #1 with Cow Feed:
     exec_cmd 0x14aae28 2300018 600003
     (Animal: 2300018 Cow, Feed: 600003 Cow Feed)

  6. Collect Finished Products from Bakery:
     exec_cmd 0x14a63f8 1300082 0

  7. Collect Finished Products from Dairy:
     exec_cmd 0x14a63f8 1300005 0

  8. Collect Eggs from Chicken Coop:
     exec_cmd 0x14a7d88 1300002 0

 6. HOW TO FIND ANY NEW ID USING THE BUILT-IN TOOLS
================================================================================

TOOL A: In the GUI (Instant Search Tab)
  1. Open `start_gui.bat`.
  2. Click the tab "ID Code Finder".
  3. Type any word (like "pie", "sugar", "axe", "milk").
  4. Click "Send to Command Builder" to immediately load it!

TOOL B: In the Command Line (game_ids.py)
  You can run:
    python game_ids.py bread
    python game_ids.py feed
    python game_ids.py 1300082
  It will instantly display the ID number, English name, and category.

TOOL C: Live Game Action Capture
  If you have a special item or building and want to know its exact ID:
  1. In the terminal, type:
       capture 60
  2. Switch to LDPlayer and tap on the building or animal.
  3. Look at the output:
       vtbl+0x014aXXXX  +24=<TARGET_ID>  +28=<PARAM2>
     The number next to `+24=` is your target's ID!

 7. HOW TO SEND SCREENSHOTS TO ADD NEW FEATURES
================================================================================
You can customize this bot simply by sending pictures!

HOW TO DO IT:
  1. Take a screenshot of what you want (your game, farm layout, or button ideas).
  2. Save the image into this folder as:
       user_screenshot.png
     (OR click "Select Screenshot" in the GUI's "Screenshot & Features" tab).
  3. Tell me in the chat:
       "I saved my screenshot as user_screenshot.png, please add the features shown in it."

The assistant will read the picture, detect the game objects and buttons, and
write the exact code to add them to your bot!
